# Math Trail

Math lessons and puzzles for grades 1 to 12. Each grade is a trail of six stops: read the lesson, solve the puzzles, and pass a stop to unlock the next one.

- `index.html` is the whole app (no build step, no dependencies). Progress is saved in the browser on each device.
- `lessons/` has a printable lesson book for every grade. Use them with the Kahoot and Blooket question sets, which hold questions only.
- `math-trail-source.zip` is the full project: separate source files, the lesson books, the Kahoot and Blooket files, and the tools that build them.
